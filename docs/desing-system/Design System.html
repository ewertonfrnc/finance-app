Princípios de cor

Todo o sistema usa oklch — hue fixo em 155–165 (verde frio) para superfícies e UI neutros. Acréscimos de chroma sinalizam ativação.

O eixo semântico de saldo (verde→amarelo→vermelho) usa hues 158 → 95 → 25, chroma crescente à medida que a situação piora.

Não há cor "nova" inventada para componentes: qualquer bg novo deve vir de um token existente ou de uma mistura via color-mix().

Tema escuro — espelha o tema dark do desktop

Acionado por FinTheme (classe body.fin-dark); os tokens mobile são gerados por mkMobileTokens(dark) e trocados in-place. As escalas semânticas (saldo, categorias, tags) ganham variantes próprias — SALDO_DARK, mkTypePalette(true), TAG_PALETTE_DARK. Hue mantido em 155–165; no escuro o fill fica profundo e o ink fica claro (inverte a relação do tema claro).
